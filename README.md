# Yousef Business Hub — مركز أعمالي

منصة عربية PHP 8+ / MySQL 5.7+ / HTML / CSS / JavaScript قابلة للاستضافة على XAMPP وInfinityFree.

## التثبيت
1. أنشئ قاعدة بيانات MySQL واستورد ملف database.sql باستخدام phpMyAdmin.
2. انسخ config.example.php إلى config.php وعدّل بيانات الاتصال. لا ترفع config.php إلى GitHub.
3. ارفع الملفات إلى htdocs أو public_html في الاستضافة.
4. افتح install.php لإنشاء حساب المدير بكلمة مرور قوية.
5. احذف install.php من الخادم بعد التثبيت.
6. افتح admin.php لإدارة المشاريع والخدمات والمنتجات وطلبات التواصل.

## الموجود حاليًا
- واجهة RTL متجاوبة مع صفحات الرئيسية والمشاريع والخدمات والمنتجات والتواصل.
- لوحة إدارة بحساب مدير محمي وتعديل وحذف ونشر المحتوى.
- استقبال طلبات العملاء وتغيير حالاتها.
- أساس PWA مع manifest وservice worker.
- حماية أساسية عبر PDO prepared statements وCSRF وpassword_hash.

## حدود النسخة
هذه نسخة أولية عاملة وليست متجر دفع مكتمل: لا توجد سلة أو دفع إلكتروني أو تنزيل محمي أو حسابات عملاء بعد. المنتجات تعرض السعر ويُرسل العميل استفسارًا. لا تدخل بيانات بطاقات دفع في هذه النسخة.

## InfinityFree
GitHub هو مستودع الشفرة، وليس الاستضافة. ارفع ملفات المشروع عبر FTP أو File Manager. ملف config.php يُنشأ على الاستضافة فقط. تحقق من دعم PHP 8 وامتداد PDO MySQL وmbstring. يجب اختبار قواعد Apache الخاصة بحجب الملفات على الاستضافة قبل النشر الفعلي.


## تحديث نَسَق v3 (أكتوبر 2026)

1. احتفظ بنسخة احتياطية من قاعدة البيانات والملفات قبل الترقية.
2. استورد `database-upgrade-v2.sql` أولًا إذا لم تستورده سابقًا، ثم `database-upgrade-v3.sql` عبر phpMyAdmin في قاعدة `if0_42930650_nasaq`.
3. ارفع ملفات PHP وCSS وJS الجديدة إلى `Nasaq.66ghz.com/htdocs` مع الحفاظ على `config.php` السري وعدم نشره في GitHub.
4. افتح `admin.php` لإدارة المحتوى؛ `admin-gallery.php?item=ID` لإدارة صور العنصر؛ `admin-orders.php` لمتابعة الطلبات؛ `admin-activity.php` لسجل النشاط؛ `settings.php` للإعدادات.
5. العميل يسجل في `account.php` ثم يطلب خدمة أو منتجًا من `item.php?id=ID`، ويتابع الطلب في `orders.php`.

**مهم:** الطلبات التجارية ليست عمليات دفع. لا يوجد حاليًا تكامل مع بوابة دفع أو Webhooks أو فواتير أو تنزيل ملفات محمي أو بريد تحقق/استعادة كلمة مرور أو نسخ احتياطي آلي. لا تستخدم النظام لتحصيل أموال قبل إضافة بوابة مرخصة، تحقق من الدفع على الخادم، حماية من الطلبات الآلية، وإجراء اختبارات أمنية شاملة. جدول `admin_roles` يوفر أساسًا للصلاحيات لكنه لا يوفّر بعد واجهة إدارة الموظفين. الحسابات المسجلة تحتاج لاحقًا تأكيد بريد إلكتروني وآلية استعادة كلمة المرور قبل الإطلاق العام.

**توافق الاستضافة:** اختبر قيود InfinityFree (الطلبات الخارجية، المهام المجدولة، البريد، الملفات) قبل اعتماد ميزات التجارة. لا تخزّن بيانات بطاقات الدفع في MySQL.
